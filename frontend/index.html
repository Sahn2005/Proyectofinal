Fundamentos

¿Qué es la Regresión Lineal?

La regresión lineal es un modelo estadístico que busca predecir un valor continuo a partir de una o más variables de entrada, asumiendo una relación lineal entre ellas.

📈

Predicción Continua

Modela relaciones entre variables de entrada y una salida numérica. Ejemplo: predecir el precio de una casa.

🔀

Diferencia con Clasificación

Mientras la regresión predice valores continuos, la clasificación asigna etiquetas discretas como "Sí/No" o categorías.

🔗

Relación con Regresión Logística

La regresión logística toma la salida lineal y la transforma con la función sigmoide para producir probabilidades entre 0 y 1.

ŷ = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ

El Clasificador

Regresión Logística como Clasificador

Transforma probabilidades en decisiones de clasificación usando la función sigmoide.

🎯

Clasificación Supervisada

Aprende de ejemplos etiquetados para predecir la categoría de nuevos datos desconocidos.

〰️

Función Sigmoide

Comprime cualquier valor real al rango [0, 1], interpretable como probabilidad de pertenencia a una clase.

⚖️

Clasificación Binaria

Si P(y=1|x) > 0.5, el modelo clasifica como positivo. De lo contrario, negativo.

σ(z) = 1 / (1 + e−z)
z = β₀ + β₁x₁ + ... + βₙxₙ

Responsabilidad

Uso Responsable de la IA

La tecnología poderosa requiere responsabilidad. Estos principios guían nuestro desarrollo.

🔍

Verificación

Valida los resultados del modelo con expertos del dominio antes de tomar decisiones críticas.

👤

Supervisión Humana

El modelo asiste, no reemplaza. Mantén siempre la supervisión humana en decisiones de alto impacto.

🔒

Protección de Datos

Los datos personales deben anonimizarse. Cumple con regulaciones como GDPR y Habeas Data.

🪟

Transparencia

Los modelos deben ser interpretables. Muestra coeficientes y explica cómo se tomó cada decisión.

⚖️

Equidad

Evalúa sesgos en los datos de entrenamiento. Los modelos pueden perpetuar desigualdades existentes.

🌍

Ética en IA

Desarrolla IA que beneficie a la humanidad. Considera el impacto social, económico y ambiental.
