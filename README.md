# Proyecto IA - Clasificador con Regresión Logística

Aplicación web educativa que implementa clasificación supervisada. 
Backend Flask REST API desplegado en Render, frontend estático en Vercel.

## Despliegue
- **Backend**: Subir carpeta `backend` a Render, configurar start command `python app.py`.
- **Frontend**: Subir carpeta `frontend` a Vercel.

Ver documentación completa en el repositorio.
